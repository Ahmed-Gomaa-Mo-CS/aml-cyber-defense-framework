# AML Cyber Defense Framework (Prototype)

## Overview
This project implements a lightweight multi-layer cybersecurity detection system combining:
- Rule-based intrusion detection
- Machine learning anomaly detection (Isolation Forest)
- Simple escalation decision engine

## Goal
To explore resource-aware adaptive cybersecurity architectures.

## Features
- Fast rule-based filtering
- ML-based anomaly detection
- Simple escalation logic
- Lightweight and runnable prototype

## Dataset
Any tabular network intrusion dataset (e.g., CIC-IDS, UNSW-NB15)

## How to Run
```bash
pip install -r requirements.txt
python main.py


## Research Direction
This prototype explores:
- Adaptive escalation mechanisms for multi-layer intrusion detection
- Resource-aware detection systems that optimize computational cost
- Multi-layer cybersecurity architectures combining rule-based, ML-based, and reasoning-based approaches
